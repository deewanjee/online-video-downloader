# Download a YouTube playlist

Load a collection, review the videos and queue your selection.

## Load the playlist

1. Use a playlist URL such as https://www.youtube.com/playlist?list=PLAYLIST_ID. A watch URL containing &list= also works.
2. Open YouTube playlist and paste the URL. Choose Load playlist. Listing can run while media downloads continue; other metadata loads and source cooldowns can still cause waiting.
3. Review the playlist title, entry count and unavailable/skipped entries. Up to 1,000 entries can be loaded; split larger playlists.

## Review availability before queueing

1. Every returned playlist entry has a status. Publicly listed means the source explicitly listed it as public; Not verified means a listing alone did not confirm access.
2. Private / sign-in, Removed, Restricted, Live / upcoming and invalid entries are visible but cannot be selected. Duplicates are disabled. Entries omitted by the source cannot be identified by this portal.
3. Choose Check next 20 selected for a sequential metadata-only access check. Repeat for the next selected batch. Available - checked confirms a usable media listing at that moment; access can still change later.
4. Queueing is disabled during a check. Cancel the check or wait for it to finish. A source cooldown or network failure stops the check without labeling untested videos as removed.

## Select and download

1. Keep Select all listed videos checked to queue the collection, or choose individual entries.
2. Choose format, quality and transfer count, then Queue all selectable videos or the selected videos. Every video becomes an independent job.
3. Review each result in the library. Dynamic Mix/radio playlists and channel URLs are not supported.

## Loading and cancellation

1. Cancel or change the URL to stop a pending playlist listing. This does not cancel downloads already queued.
2. A preview expires after thirty minutes or app restart. Repeated submission of the same preview does not create a duplicate batch; load again for a fresh import.
