Choose where files are saved

Understand direct laptop saving, server mode and backups.

Download guide
Local desktop savingFiles and temporary workHosted or server mode

Local desktop saving

  1. Use the local Start StreamVault.bat launcher. In Download location choose an existing writable folder, for example D:\Videos.
  2. If the native dialog is unavailable, expand Enter folder path instead and enter the full absolute path. Folder selection is available only on the computer running the local desktop launcher.
  3. The chosen folder is remembered. Changing it affects newly queued jobs; current jobs keep their recorded destination.

Files and temporary work

  1. Media components and merging use .aaasoft-work inside the selected folder. Successful originals are renamed into that folder, avoiding a second original in project data.
  2. The project data directory still holds history, posters and optional compatible previews. Keep it when updating.
  3. In direct mode, Folder opens the original location. Save a copy in the player is optional. Existing old files are not automatically moved.

Hosted or server mode

  1. A remote web server cannot choose a folder on your laptop. Save to device uses your browser download settings after server processing.
  2. Back up app data and selected output folders. Keep .venv, .env and data when replacing project files.
