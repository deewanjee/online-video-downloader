# Formats and quality

Choose useful output settings without unnecessary processing.

## Video formats

1. MP4 offers broad compatibility. The app prefers H.264/AAC when available and merges separate audio/video tracks as needed.
2. WebM preserves common web video codecs. MKV is a flexible container; browser-native playback varies.
3. 1080p is a good balance for many sources; choose 720p to reduce storage and transfer needs. 4K is available only when the source provides it.

## Audio formats

1. MP3 extracts audio for broad playback support. M4A and WAV are also available. A source without an audio track cannot produce an audio-only download.
2. WAV files can be much larger. Audio extraction/conversion uses FFmpeg.

## What the quality setting means

1. Maximum quality is a cap, not an upscaler. If only a higher source resolution is offered, resizing can add processing time.
2. Download speed depends on source servers, network, source limits and conversion. The portal cannot guarantee a fixed completion time.
